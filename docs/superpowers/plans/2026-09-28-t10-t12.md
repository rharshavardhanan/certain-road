## Brainstorm — what the spec did not state

The libraries (`assess/conformal.py`, `assess/drift.py`, `core/geometry.py`,
`survey/scoring.py`, `survey/allocation.py`) and their spec'd unit tests already
exist. What is missing is the experiment layer, and three constraints the spec
predates:

- **T10 resampling is over scene groups (D064), not images.** The spec says
  "random re-partitions"; D064 amended that. Group sizes vary, so realised
  calibration sizes will vary slightly around the original — report the range.
- **T10 alphas come from the floor (D070/D076).** Model A calibrated on India is
  infeasible below 0.64. Infeasible is reported as `None`, never as a failure.
- **The certificate controls misses, not false alarms.** At tight alpha the
  certified tau is ~0.001-0.01, where D074 measured 5-30 false alarms per image.
  T10 must report false alarms per image at tau-hat next to the certified risk,
  or it describes an operating point nobody could run.
- **T12 as built cannot show robustness matters.** One scalar damage times one
  global recall is rank-preserving, so nominal and robust choose identically by
  construction. Rebuild detection per class, through the real scoring pipeline.
- **"Model B" headlines T10 and feeds T12**, as the spec's T10 and T12 both name
  it, and D076 shows B certifies the tighter miss rate. P is reported alongside
  because D074 carries P forward.

## Task 1 — T10: certified thresholds and the shift violation, from locked predictions

**Goal** `results/T10/conformal.{json,md}` reports, for every calibration case and
alpha, tau-hat, n, test image-level risk, instance miss rate and false alarms
per image, plus 200 group-aware re-partitions confirming mean test risk <= alpha
for India calibration and measuring the violation for non-India calibration.

**Why** T12's robust policy and its detector model both read T10's outputs. Until
they exist, T12 runs on a stand-in recall of 0.75.

**Files** `scripts/exp_conformal.py`; `results/T10/`

**Steps**
1. Precompute matched confidences once per image per model (A: nonindia_val open
   + india_full locked; B, P: india_heldout locked).
2. Cases: A nonIndia->test, A india_cal->test, B india_cal->test, P india_cal->test.
3. Alphas: configured list plus the full floor-to-0.96 curve; tau grid from
   `default_tau_grid(tau_step)`.
4. 200 re-partitions of india_cal U india_test permuting scene groups; each India
   case recalibrates on the resampled cal half; A's non-India tau-hat is applied
   to the same resampled test halves.
5. JSON + authored-free generated markdown.

**Done when** `uv run python scripts/exp_conformal.py` prints, for B at every
feasible configured alpha, mean resampled test risk <= alpha, and writes
`results/T10/conformal.json`.

## Task 3 — T11: drift alarm on real predictions

**Goal** False-alarm rate under the null over 200 shuffles, and detection delay
over 200 null->India streams, from Model A's predictions.

**Why** The drift alarm is the runtime answer to T10's violation: it is how a
deployed system would know it had left the domain its certificate covers.

**Files** `scripts/exp_drift.py`; `configs/project.yaml` (post-shift length);
`results/T11/`

**Steps**
1. Frame scores from A's nonindia_val (open) and india_full (locked) predictions.
2. Seeded 50/50 split of nonindia_val into reference bag and null pool.
3. Null: 200 shuffles, alarm rate vs 1/threshold.
4. Shift: 200 streams of `null_prefix` null frames then shuffled India frames;
   delay after the shift; pre-shift alarms counted as false alarms.
5. Traces + delay histogram.

**Done when** null false-alarm rate <= 1/alarm_threshold is printed with its
count, and a median delay is reported with the undetected count.

## Task 4 — T12: detection error that can actually change a decision

**Goal** The allocation experiment simulates per-class instances, detects them by
Binomial thinning at Model B's per-class recall at T10's tau-hat, scores segments
through `vision_density -> deduct_value -> vision_estimated_pci`, and compares
nominal, robust (pothole density / (1 - alpha)), greedy worst-first and random.

**Why** As built, nominal and robust cannot differ. The experiment would report
"robustness changes nothing" as a property of its own construction.

**Files** `scripts/exp_allocation.py`; `configs/project.yaml` (generator
parameters); `results/T12/`

**Steps**
1. Read tau-hat and alpha from `results/T10/conformal.json`; measure B's per-class
   recall at tau-hat on locked india_test.
2. Per segment and class: true instance count and footprints from a documented
   generator; true and observed vision-estimated PCI through the real functions.
3. Policies on observed / robust-observed; metrics on the truth.
4. Budgets 10-50%, 1,000 trials; figure per metric.

**Done when** `results/T12/allocation.json` names the tau-hat and recall it used
(no stand-in), and nominal and robust are reported separately.
